# Raw HR Dataset

This folder contains the original HR dataset before data cleaning or preprocessing.

## Purpose
The raw dataset is the starting point for the project’s data preparation workflow.

## Workflow
1. Inspect the dataset and its column types.
2. Check for missing values, duplicates, and inconsistent values.
3. Document the cleaning steps.
4. Save the prepared output in `data/cleaned/`.

## Note
Keep the original dataset unchanged. Only upload public data or data you are authorized to share. Remove or anonymize personal and confidential employee information.
