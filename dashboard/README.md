# Power BI Report

Power BI report file: [HR Project.pbix](HR%20Project.pbix)

## Report Pages

1. **Global HR Dashboard** — workforce KPIs, salary by department, employee count by department, and gender distribution.
2. **Turnover & Retention Analysis** — turnover indicators, terminated employees by department and gender, tenure of leavers, and termination trend by year.
3. **Performance & Salary Analysis** — salary distribution, average performance rating, high-performance share, satisfaction, and engagement versus salary.
4. **Diversity & Demographics Analysis** — gender, age groups, tenure, positions, and terminated employees by department.

## Open the Report

1. Download the .pbix file and open it in Power BI Desktop.
2. If prompted, update the CSV source path to the dataset in ../data/cleaned/HRDataset_v14.csv or your local copy.
3. Refresh the data and verify the measures before interpreting the results.

## Tools

- Power BI Desktop
- Power Query for data import/transformation
- DAX measures and KPI calculations

## Important

The metric definitions depend on the report's data model and DAX. Confirm the exact logic for active employee rate, turnover rate, high-performance share, and average tenure before reusing these measures. Publish only data you are authorized to share.
